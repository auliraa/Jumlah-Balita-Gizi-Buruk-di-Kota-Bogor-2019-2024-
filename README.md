
Proyek ini adalah eksplorasi data mendalam untuk mengungkap tren status gizi balita
di Provinsi Jawa Barat dari tahun 2019 hingga 2024. 👶🩺 Dengan fokus studi kasus pada Kota Bogor,
analisis ini bertujuan untuk mengubah data mentah menjadi visualisasi yang informatif dan mudah dipahami

Dari data mentah, kita menemukan adanya lonjakan kasus pada tahun 2020 yang diikuti oleh **penurunan signifikan** pada tahun-tahun berikutnya, menunjukkan potensi keberhasilan program kesehatan atau perubahan kondisi sosial.

✅ Fitur Utama & Proses Analisis
  - **Pembersihan & Persiapan Data** : Memuat data dari file `.csv` dan memastikan data bersih dari nilai null serta memiliki tipe data yang sesuai menggunakan `pandas`.
  - **Analisis Data Eksploratif (EDA)** : Melakukan `value_counts()` dan `describe()` untuk memahami distribusi dan karakteristik data.
  - **Filtering & Agregasi** : Memfilter data untuk studi kasus spesifik (Kota Bogor) dan mengelompokkan data berdasarkan tahun untuk melihat tren waktu.
  - **Visualisasi Data** menggunakan `matplotlib` untuk validasi data
    
🛠️ Teknologi yang Digunakan
  - Python 🐍
  - Pandas 🐼 
  - Matplotlib 📉 
  - VS Code 📓 

🗂️ Sumber Data
Data yang digunakan dalam analisis ini adalah data publik yang berasal dari **Portal Open Data Provinsi Jawa Barat**.

  - **Nama Dataset**: Jumlah Balita Berdasarkan Kategori Balita Gizi Buruk
  - **Tautan**: [data.jabarprov.go.id](https://www.google.com/search?q=https://data.jabarprov.go.id/jabardata/dataset/dinkes-od_17107_jml_balita__kategori_balita_gizi_buruk_v5_data)
